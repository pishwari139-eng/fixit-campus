# FixIt Campus

FixIt Campus is a campus problem reporting and tracking system.

It allows students to report problems related to maintenance, equipment,
network, and classrooms. Reported problems can be searched, filtered, and
their status can be updated.

## Features

- Report campus problems
- Validate problem form inputs
- Search reported problems
- Filter problems by category and status
- Update problem status
- JSON API for reported problems
- Health check endpoint
- Docker support
- Automated testing with pytest
- Code quality checking with Flake8
- GitHub Actions CI pipeline

## Technologies Used

- Python
- Flask
- HTML
- Docker
- Git and GitHub
- GitHub Actions
- pytest
- Flake8
